## 题目

给定 n 个整数 a，正数表示收益，负数表示损失。检测窗口必须恰好包含连续 k 个元素。

若窗口内元素总和至少为 S，且负数数量至多为 c，则窗口合格。统计合格窗口数量；起点不同算不同窗口。0 不算负数。

### 输入格式

第一行 n k S c；第二行 n 个整数。输出一个整数，表示合格窗口数量。

```text
1 ≤ k ≤ n ≤ 200000
0 ≤ c ≤ k
-10^9 ≤ S ≤ 10^9
-10^6 ≤ a[i] ≤ 10^6
```

### 样例输入

```text
6 3 3 1
4 -2 5 -1 3 -4
```

### 样例输出

```text
2
```

合格窗口为 [4, -2, 5] 和 [5, -1, 3]，总和均为 7，各含一个负数。

## 第一轮任务

先说明最直接的算法及其复杂度，再说明从一个窗口移动到下一个窗口时，哪些元素发生变化，以及准备维护什么信息。暂不提供实现模板。

## 学习记录

### 初始尝试与修正

学习者独立维护窗口总和 total 与负数数量 cnt。初次提交用 i < k 跳过未满窗口，导致漏掉第一个完整窗口；移出下标写为 i - k，与“检查后移出”顺序不一致；移出负数时没有同步减少 cnt。

提示给出第一个完整窗口在 i = k - 1、左端为 i - k + 1，以及移出时同步维护两个量。学习者随后提交了正确代码，记录为提示后完成，而非完全独立完成。

### 最终提交

```python
if __name__ == '__main__':
    n, k, s, c = map(int, input().split())
    nums = list(map(int, input().split()))
    ans = 0
    total = 0
    cnt = 0
    n = len(nums)
    for i in range(n):
        total += nums[i]
        if nums[i] < 0:
            cnt += 1
        if i < k - 1:
            continue
        if total >= s and cnt <= c:
            ans += 1
        total -= nums[i - k + 1]
        if nums[i - k + 1] < 0:
            cnt -= 1
    print(ans)
```

输入已保证有 n 个元素，n = len(nums) 可以省略；它在合法输入下不影响结果。

### 维护的信息与正确性

加入 nums[i] 后，在进行条件判断时，total 和 cnt 分别对应区间 [i - k + 1, i] 的总和和负数数量。i < k - 1 时尚未形成完整窗口，不计数也不移出。

完整窗口检查后，移出其最左端，留下 k - 1 个元素供下一轮扩展。每个长度为 k 的窗口按右端点出现一次，故不重不漏。数组允许负数不影响这种固定长度移动规则。

### 复杂度与实际验证

时间 O(n)，除输入数组外额外空间 O(1)。每个元素加入一次，且最多移出一次。

对最终提交实际运行 6 个固定用例和 2,000 个固定种子随机用例，与逐窗口切片求和、数负数的直接方法对拍，全部一致。固定用例覆盖题面样例、单元素、全零、k = n、负数数量恰好达到或超过限制。未提交到外部在线评测。
