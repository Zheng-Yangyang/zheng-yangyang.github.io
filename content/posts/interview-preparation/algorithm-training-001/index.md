## 题目：合格的观测片段

仪器依次记录了 n 个整数，第 i 个记录为 a[i]。正数表示增加，负数表示减少。

一个连续、非空的观测片段被称为合格，需要同时满足：

1. 片段包含的记录数量至少为 p，至多为 q。
2. 片段内所有记录的总和至少为 T。

请统计合格片段的数量。起点或终点不同，就算不同片段，即使片段中的数值相同。

### 输入

第一行包含四个整数，顺序如下：

```text
n p q T
```

第二行包含 n 个整数。

### 输出

输出一个整数，表示合格片段的数量。

### 数据范围

```text
1 ≤ n ≤ 3000
1 ≤ p ≤ q ≤ n
-10^6 ≤ a[i] ≤ 10^6
-10^9 ≤ T ≤ 10^9
```

### 样例一

输入：

```text
5 2 3 3
3 -2 4 -1 2
```

输出：

```text
3
```

采用从 1 开始的下标，三个合格片段为 [1, 3]、[3, 4]、[3, 5]，总和分别为 5、3、5。

### 样例二

输入：

```text
1 1 1 0
0
```

输出：

```text
1
```

## 学习过程

### 起点与真实卡点

学习者独立提出了前缀和加双重循环的思路，并判断最坏时间复杂度为 O(n²)。困难主要出现在定义与下标的对应，而不是不知道使用什么算法。

最初代码的前缀和漏掉 nums[0]；长度枚举从 0 开始，实际计算的长度与题目要求不一致；右边界没有覆盖最后一个前缀位置。明确“pre[k] 是前 k 个元素之和”后，能够正确写出区间差值；手算 pre[5] 时出现加法错误，随后纠正。

在提示下将 right 解释为不包含的右边界，将 length 解释为实际长度，并通过 min(q, right) 排除越过左端的片段。第二版代码仍漏算 pre[n]，最终将构造循环改为 range(1, n + 1)。学习者反馈两个题面样例分别输出 3 和 1。

### 正确性解释

学习者指出：确定一端的边界与长度，就能确定另一端。这里需要补充：不重不漏的依据是合法片段与 (right, length) 之间的一一对应，以及循环覆盖全部合法组合；仅凭边界单调变化不能保证枚举完整。

任意合法片段 [left, right) 唯一对应 length = right - left。其 right 在 [p, n]，length 在 [p, min(q, right)] 内，必然被枚举。反过来，循环中的每个组合都确定一个合法长度、合法下标的非空片段。每个组合出现一次，因此没有重复或遗漏。

定义 pre[k] 为前 k 个元素之和，则片段总和为 pre[right] - pre[right - length]；判断总和至少为 T 后计数即可。

### 最终代码

以下保留最终提交的算法，移除原注释中不精确的运算次数估计。

```python
if __name__ == '__main__':
    n, p, q, T = map(int, input().split())
    nums = list(map(int, input().split()))
    pre = [0] * (n + 1)
    for i in range(1, n + 1):
        pre[i] = pre[i - 1] + nums[i - 1]
    ans = 0
    for right in range(p, n + 1):
        for length in range(p, min(q, right) + 1):
            total = pre[right] - pre[right - length]
            if total >= T:
                ans += 1
    print(ans)
```

### 复杂度

构造前缀和需要 O(n) 时间。枚举次数为 sum(min(q, right) - p + 1)，其中 right 从 p 到 n。总时间为 O(n × (q - p + 1))，最坏 O(n²)，额外空间为 O(n)。n = 3000 且允许所有长度时，实际枚举 4,501,500 个片段。
