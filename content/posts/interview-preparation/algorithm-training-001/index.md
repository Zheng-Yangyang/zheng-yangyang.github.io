## 题目：合格的观测片段

仪器依次记录了 n 个整数，第 i 个记录为 a[i]。正数表示增加，负数表示减少。

一个连续、非空的观测片段被称为合格，需要同时满足：

1. 片段包含的记录数量至少为 p，至多为 q。
2. 片段内所有记录的总和至少为 T。

请统计合格片段的数量。起点或终点不同，就算不同片段，即使片段中的数值相同。

### 输入

第一行包含四个整数，顺序如下：

```text
n p q T
```

第二行包含 n 个整数。

### 输出

输出一个整数，表示合格片段的数量。

### 数据范围

```text
1 ≤ n ≤ 3000
1 ≤ p ≤ q ≤ n
-10^6 ≤ a[i] ≤ 10^6
-10^9 ≤ T ≤ 10^9
```

### 样例一

输入：

```text
5 2 3 3
3 -2 4 -1 2
```

输出：

```text
3
```

采用从 1 开始的下标，三个合格片段为 [1, 3]、[3, 4]、[3, 5]，总和分别为 5、3、5。

### 样例二

输入：

```text
1 1 1 0
0
```

输出：

```text
1
```
