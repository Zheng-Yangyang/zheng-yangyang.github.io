## 题目：片段内的上升次数

有 n 次连续观测，记录为整数 a[1], a[2], ..., a[n]。数据不会修改。

若相邻两次记录满足 a[i] < a[i + 1]，就称这两次记录之间发生了一次上升。相等不算上升。

给出 m 次查询，每次指定一个闭区间 [l, r]。请统计该片段内部的上升次数。相邻的两个位置必须都在查询区间内。

### 输入格式

第一行两个整数 n、m。第二行 n 个整数。接下来 m 行，每行两个整数 l、r。题面下标从 1 开始。

### 输出格式

每次查询输出一行，表示上升次数。

### 数据范围

```text
1 ≤ n, m ≤ 200000
-10^9 ≤ a[i] ≤ 10^9
1 ≤ l ≤ r ≤ n
```

### 样例

输入：

```text
6 4
4 7 7 2 5 8
1 6
2 4
4 6
3 3
```

输出：

```text
3
0
2
0
```

整个数组中，4 到 7、2 到 5、5 到 8 各算一次上升。区间 [2, 4] 中只有 7、7、2，没有上升。单元素片段不存在相邻的两个位置，上升次数为 0。

## 2026-10-19 学习过程

学习者独立提出记录“前 i 个元素内部的上升次数”，并正确手算出样例的整个前缀数组。最初将直接查询的复杂度判断为 O(n²m)，混淆了枚举所有片段与扫描指定片段；明确每次查询的端点已给定后，修正为最坏 O(nm)。

递推表达式最初把 else 0 作用于整个赋值，提示后明确应只给新增次数加 0。查询先提出 pre[r] - pre[l - 1]，经跨左边界恰好上升的反例，明确应排除这条关系，得到 pre[r] - pre[l]。

实现时出现 map 不能使用 len 或下标、输入格式不一致、0-based 元素下标与前缀长度混用等问题。学习者要求完整代码后，提供了统一 1-based 的实现。随后讨论数组前加占位元素只是编号选择，与前缀数组保留空前缀不同。

### 参考代码

```python
if __name__ == '__main__':
    n, m = map(int, input().split())
    nums = [0] + list(map(int, input().split()))
    pre = [0] * (n + 1)
    for i in range(2, n + 1):
        pre[i] = pre[i - 1] + (1 if nums[i] > nums[i - 1] else 0)
    for _ in range(m):
        l, r = map(int, input().split())
        print(pre[r] - pre[l])
```

pre[k] 表示前 k 个元素内部的上升次数，单元素为 0。相减时 pre[l] 排除左端外到左端的关系。时间 O(n + m)，空间 O(n)。
